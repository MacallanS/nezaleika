# `bibli/shared/ui/rr`

Импортировать из `bibli/shared/ui/rr`, не из подпапок.

| Папка | Содержимое |
|-------|------------|
| `form/` | `AuthRR*` — кнопки, поля, OTP, правила пароля |
| `list/` | `RrGridList`, тулбар, чипы, бейджи, поиск |
| `overlays/` | `RrBottomSheet`, `RrSelectSheet` |
| `lib/` | пресеты статусов |

Экраны (layout, wizards, списки оформления) живут в `bibli/widgets/{Auth,Profile,Layout,Onboarding}`.
