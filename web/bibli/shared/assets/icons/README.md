# Shared icons — `bibli/shared/assets/icons`

Единая точка для общих SVG. Импорт: `bibli/shared/assets/icons`.

## Использование

```ts
// URL (для <img :src>)
import { icons } from 'bibli/shared/assets/icons'
const src = icons.phone

// Сырой SVG (inline + currentColor)
import phone from 'bibli/shared/assets/icons/phone.svg?raw'
```
